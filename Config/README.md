# Dossier config

Ce dossier contient toutes les configurations utilisées par ModuleSMS.

## Contenu
- `profiles/` : profils de configuration (default, legion)
- `default.conf` : configuration standard
- `legion.conf` : configuration style Légion étrangère
- `settings.yaml` : paramètres généraux du module

## Objectif
Centraliser les réglages pour adapter ModuleSMS à différents environnements Termux.
