# Dossier src

Ce dossier contient le code source principal de ModuleSMS.

## Structure
- `bash/` : scripts Bash (dump, export, surveillance)
- `python/` : scripts Python (parser, stats, export)
- `termux/` : scripts utilisant termux-api

## Objectif
Fournir les outils nécessaires pour extraire, analyser et surveiller les SMS.
